# Science explainers and language review

Read and obey the project's content, visual, narration, curriculum, copyright, and review guidelines. The generic catalogs contain trailer/ad pacing, typography, and sound directions; these never override educational comprehension or scientific correctness.

- Keep 1 concept, 1 learning objective, and 1 understanding check. Start with an observation/question, build a model, reveal the mechanism, pause for a check, and summarize the relationship and limits.
- Measure narration before fixing scene durations. Allow reading, looking, and thinking time. Do not estimate Burmese speech duration from whitespace word counts. Use a draft voice recording or actual approved narration. The planner's initial beat allocation is scaffolding.
- When the requested language is Burmese, write Unicode with reviewed terminology. Use a licensed Myanmar-capable font, verify loaded family/weight, inspect combining marks/stacked glyphs and line breaks on the actual backend, and obtain fluent-language review before presenting the release as language-reviewed. Keep drafts moving while clearly marking pending review. A font's presence or successful Rust compilation does not prove correct shaping.
- Prefer phrase/line reveals. If character reveals are necessary, segment grapheme clusters rather than Unicode scalar values or bytes so combining marks remain intact. Do not compress type to satisfy a preset's one-line headline or all-uppercase rules.
- Use project safe areas and caption placement, not generic platform estimates. Test readability at the intended viewing size; use the actual device when available and report the scope of review accurately.
- Compute trajectories, graphs, units, proportions, and relationships from a documented model. Physical state must not depend on decorative easing. Note simplified speeds/scales, idealizations, and boundaries of validity. Keep arrow directions and variables consistent across scenes.
- Use reliable scientific sources; when curriculum alignment is requested, link the lesson to verified textbook metadata. Distinguish extraction/transcription from scientific and curriculum verification. Use original diagrams and scripts; catalog art direction is not permission to reuse textbook figures.
- Favor calm motion, stable reference frames, semantic colors, and one changing relationship at a time. Use music/accents only when they aid attention; keep narration intelligible. Teaching holds are valid, so record them in `planned_holds` when using planner-based QC, or in a short review note, rather than inventing decorative motion to evade freeze detection.
- Keep scene examples and generated plans in project lesson/output paths. Retain the authoritative lesson metadata and human review records. A technical QC pass does not establish completed scientific or language review.
